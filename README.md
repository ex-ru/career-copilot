# 🚀 Career Copilot

**Автономный AI-ассистент карьерного позиционирования, интервьюер кандидата и движок генерации адаптированных резюме.**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-brightgreen.svg)](https://www.python.org/)
[![Code Style](https://img.shields.io/badge/UI-Rich%20Terminal-cyan.svg)](https://github.com/Textualize/rich)

Career Copilot решает главную боль активного поиска работы: **рутинную ручную адаптацию резюме и сопроводительных писем под каждую целевую вакансию**. 

Инструмент помогает извлечь оцифрованные метрики и скрытые достижения из вашего реального опыта, формирует мастер-матрицу компетенций и автоматически генерирует персонализированные пакеты документов (Markdown + стилизованный DOCX Word) под любое количество вакансий.

---

## 🌟 Ключевые возможности

- 🎙️ **Двухрежимный онбординг кандидата:**
  - **Экспресс-режим (Fast Track):** Положите ваше старое резюме, сертификаты или диплом в папку `data/inputs/`. AI проведет аудит, найдет пробелы и задаст точечные вопросы для извлечения метрик.
  - **Глубокое карьерное интервью:** Интерактивный диалог в терминале с AI-консультантом уровня CTO/VP of Engineering. Вытаскивает реальные кейсы (STAR/XYZ), масштаб систем и формирует каноническую матрицу навыков `data/skills_matrix.md`.
- 💼 **Мультиформатный импорт вакансий:**
  - Скачивание и очистка текста вакансий по URL (LinkedIn, HeadHunter, Habr Career, корпоративные сайты).
  - Поддержка локальных файлов (`.txt`, `.md`, `.pdf`) в `data/vacancies/`.
  - Вставка текста вакансии прямо в консоли.
- 🎯 **Интеллектуальный анализ совпадения (Matching Engine):**
  - Расчет Fit Score (0-100%).
  - Карта покрытия стека (полное / частичное / пробел).
  - Формирование стратегии позиционирования и нивелирования недостающих навыков.
- 📄 **Генерация полного пакета документов под вакансию:**
  - Адаптированное резюме (RU / EN / оба языка).
  - Персонализированное Cover Letter с фокусом на боли работодателя.
  - Аналитический отчет `matching_analysis.md`.
  - **Автоматическая компиляция в представительский Microsoft Word (.docx)** в корпоративном стиле (шрифты Calibri, Navy-заголовки, тонкие границы, аккуратные списки).
- 📊 **Сводный аналитический отчет (`vacancy_analysis_report.md`):**
  - Сравнительная таблица всех вакансий, оценка шансов и приоритеты отклика.
  - Анализ совокупного спроса на технологии.
- 🔒 **100% приватность:**
  - Ваши персональные данные, резюме, вакансии и сгенерированные файлы находятся в локальной директории `data/` и **надежно исключены из Git через `.gitignore`**.
- 🤖 **Любой AI-провайдер:**
  - OpenAI (GPT-4o, o3-mini)
  - Google Gemini (Gemini 2.0 Flash / Pro)
  - Anthropic Claude (через OpenRouter)
  - Полностью бесплатные и приватные локальные модели через **Ollama** (Llama 3.1, Qwen 2.5, DeepSeek-R1) без отправки данных в облако!

## 🚀 Два режима использования

Вы можете использовать проект **двумя разными способами** в зависимости от ваших предпочтений:

---

### Вариант А. Внутри AI-редакторов (Antigravity, Claude Code, Cursor, Codex) — БЕЗ API-КЛЮЧЕЙ! 🪄

Если у вас уже установлен **Google Antigravity**, **Claude Code**, **Cursor** или **Codex/Copilot**, вам **НЕ НУЖНО настраивать никакие API-ключи** и тратить деньги на токены! Встроенный AI-агент редактора сам берет на себя роль карьерного консультанта.

1. **Склонируйте и откройте репозиторий** в вашей среде (Antigravity / Cursor / Claude Code):
   ```bash
   git clone https://github.com/ex-ru/career-copilot.git
   ```
2. **Установите зависимости** (нужны только для сборки Word DOCX):
   ```bash
   pip install -r requirements.txt
   ```
3. **Просто общайтесь с агентом в чате!**  
   Агент автоматически подхватит инструкции из [`AGENTS.md`](AGENTS.md), [`CLAUDE.md`](CLAUDE.md) и [`.cursorrules`](.cursorrules).
   * Напишите: *"Проведи со мной карьерное интервью и составь skills_matrix.md"*
   * Положите файл вакансии в `data/vacancies/` (или отправьте ссылку в чат) и напишите: *"Адаптируй резюме под эту вакансию"*.
   * Агент сам сформирует аналитику, напишет адаптированное резюме, персонализированное письмо и скомпилирует стилизованный Word-файл (`.docx`)!

---

### Вариант Б. Автономное CLI-приложение в терминале (с API или локальной моделью) 💻

Если вы хотите запускать скрипт независимо от редактора в любом обычном терминале:

#### 1. Установка зависимостей
```bash
python -m venv venv
# Windows: venv\Scripts\activate | Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
```

#### 2. Настройка подключения к AI
Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваш вариант:

* **OpenAI (ChatGPT):**
  ```env
  OPENAI_API_KEY=sk-proj-...
  LLM_MODEL=gpt-4o-mini
  ```
* **Google Gemini (быстро и экономично):**
  ```env
  OPENAI_API_KEY=AIzaSy...
  OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
  LLM_MODEL=gemini-2.0-flash
  ```
* **Локальный сервер llama.cpp (100% оффлайн в локальной сети):**
  ```env
  OPENAI_BASE_URL=http://192.168.1.166:8080/v1
  LLM_MODEL=default
  ```
* **Бесплатный локальный Ollama:**
  ```env
  OPENAI_BASE_URL=http://localhost:11434/v1
  LLM_MODEL=llama3.1
  ```

#### 3. Запуск интерактивного меню
```bash
python run.py
```
*(Проверить подключение можно командой `python run.py --test-ai`).*

## 💡 Типовой сценарий работы

1. **Онбординг (1-2 минуты):**  
   Запустите `python run.py`, выберите пункт `1`.  
   Либо положите старое резюме в `data/inputs/` и запустите экспресс-аудит, либо пройдите 5-минутное интервью с AI для извлечения метрик. В результате создается `data/skills_matrix.md`.
2. **Добавление вакансий:**  
   Выберите пункт `2`. Вставьте ссылку на вакансию с HeadHunter/LinkedIn или закиньте текстовый файл в `data/vacancies/`.
3. **Генерация пакетов:**  
   Выберите пункт `3` (под одну вакансию) или пункт `4` (пакетная обработка всех вакансий).  
   AI сгенерирует в `data/output/<вакансия>/`:
   - `matching_analysis.md`
   - `CV_Tailored_RU.md` и `CV_Tailored_RU.docx`
   - `CV_Tailored_EN.md` и `CV_Tailored_EN.docx`
   - `Cover_Letter_RU.md` и `Cover_Letter_RU.docx`
   - `Cover_Letter_EN.md` и `Cover_Letter_EN.docx`
4. **Сводный анализ:**  
   Выберите пункт `5` — получите сравнительную таблицу всех вакансий со скорингом шансов и стратегией отклика!

## 🛠 Автономный конвертер Markdown -> DOCX

Вы можете использовать встроенный движок верстки DOCX независимо:
```bash
python run.py --docx -i my_resume.md -o my_resume.docx
```
